Style rules for generated letters:
- 4–5 short paragraphs, 200–300 words
- Open with the exact job title and one specific line about this company's need
- Use 2–3 achievements from cv.md that match the job's top requirements
- Name the gap honestly where it helps ("I haven't used Deluge yet; I've written similar logic in…"), but only if it's true
