## Lessons for the build
1. **"Remote" usually isn't worldwide.** Region locks were the #1 reason for dropping a job. Read the structured location fields first.
2. **Country versions:** some companies post one job per country (PartnerOne: US $130–140K, Chile, Mexico, plus an "Anywhere" version on WWR). Link the version she can apply for.
3. **Stale posts float around** aggregator sites for months. The original posting date matters.
4. **Many aggregators are copies.** Remotive, Jobgether, RemoteRocketship, DailyRemote, WhyNotRemote and others repost the same jobs. Dedupe hard and prefer the employer/ATS link.
5. **Email-apply jobs exist** (Kreative Media: subject line must match exactly). The email draft must copy the subject the posting asks for.
6. **LinkedIn can't be fetched** without login. Use paste-a-link + paste-the-text instead.
7. **Prior art worth reading:** Career-Ops (github.com/santifer/career-ops, a Claude Code job-search system with scoring, portal scanning and a tracker) and jobspy-mcp (JobSpy as an MCP server; it scrapes, so keep it optional).
