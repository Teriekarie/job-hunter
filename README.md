# Job Hunter

Private job search and application tracker for Theresa (Thess) Karamor.
Searches 7 job boards every day, drops jobs that are old, closed, fake-looking or closed to Nigeria,
scores the rest against her CV, prepares emails and cover letters, and tracks every application.
